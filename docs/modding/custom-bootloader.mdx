The custom bootloader protects the device from Hard Brick by preventing critical operations such as flashing the preloader and locking the bootloader without restoring the original firmware.

In addition, it extends the functionality by adding new options for customizing and managing the system.

## Kaeru

:::info
Thanks to [Roger Ortiz](https://github.com/R0rt1z2) for developing the payload for our bootloader!
:::

### Features
- Blocks ```fastboot flash``` on critical partitions
- Blocks ```fastboot erase``` on critical partitions
- Blocks ```fastboot flashing lock```
- Removes Tinno factory mode
- Removes secure state
- Removes orange state warning
- Removes fuse check
- Removes bootloader auto-lock security feature
- Spoofes verified state to green
- Spoofes device as development unit
- Adds ```fastboot oem bldr_spoof```

### Install
:::warning
Initial installation requires an engineering DA (Use AMT Tool for example).

To upgrade or rollback to another version of Kaeru you can use mtkclient or fastboot
:::

#### Prebuild images

export const groupedKaeru = imagesKaeru.reduce((acc, item) => {
    if (!acc[item.payload_version]) {
        acc[item.payload_version] = [];
    }
    acc[item.payload_version].push(item);
    return acc;
}, {});

{Object.keys(groupedKaeru).map(payload_version => (
<details key={payload_version} className="custom-details">
<summary>Kaeru v{payload_version}</summary>
<ul>
{groupedKaeru[payload_version].map(item => (
<a href={item.url}><li key={item.firmware_version}>{item.firmware_version}</li></a>
))}
</ul>
</details>
))}

<br />

#### Manually build
1. Download your current firmware archive from [lolinet](https://mirrors.lolinet.com/firmware/lenomola/2024/fogorow/official/)
2. Clone repository ```
    $ git clone https://github.com/R0rt1z2/kaeru``` **(branch main)**
3. Transfer the ```lk.img``` file from the firmware archive to the directory ```kaeru/lk```
4. Install dependencies
     ```shell
     $ sudo pacman -S git python arm-none-eabi-gcc arm-none-eabi-newlib
     ```
5. Build and patch
     ```shell
     $ ./build.sh fogorow lk/lk.img
     ```

## ChikiChou

:::info
Forked from [ChouChou](./custom-bootloader-chouchou.mdx)
:::

<img src={chikichou} width="300" />

### Features

- Adds ```fastboot oem download``` alias for ```fastboot download```
- Adds ```fastboot oem help```
- Adds ```fastboot oem is-partition-protected```
- Adds ```fastboot oem ssm enable-thinkshield```
- Adds ```fastboot oem ssm enable-zerotouch```
- Blocks ```fastboot erase``` on critical partitions
- Blocks ```fastboot flash``` on critical partitions
- Blocks ```fastboot flashing lock```
- Blocks ```fastboot flashing unlock```
- Hides bootloader orange state warning
- Hides useless information from screen when is into bootloader mode
- Patches ```fastboot oem ssm disable-thinkshield```
- Patches ```fastboot oem ssm disable-zerotouch```
- Publishes ```chikichou-version```
- Publishes ```membase```

#### Specific features, only for our device
- The bootloader auto-lock security feature has been removed
- Preventing factory mode
- Fuse check
- Added ability to flash any partition

## ChouChou

:::warning
THIS HAS BEEN DEPRECATED. USE KAERU OR CHIKICHOU INSTEAD
:::

:::info
Thanks to [Roger Ortiz](https://github.com/R0rt1z2) for developing the payload for our bootloader!
:::

It was originally developed for [penangf (Moto G13/G23)](https://penangf.fuckyoumoto.xyz/docs/modding/custom-bootloader), but was ported for fogorow keeping all functionality and adding new functionality specific to our device.

### Features
- Blocks ```fastboot flash preloader```
- Removes orange state
- Spoofes verified state to green
- Block ```fastboot flashing lock```
- Adds ```fastboot oem help```
- Adds ```fastboot oem hexdump```
#### Specific features, only for our device
- The bootloader auto-lock security feature has been removed
- Preventing factory mode
- Fuse check
- Added ability to flash any partition

To upgrade or rollback to another version of ChouChou you can use mtkclient or fastboot

#### Manually build

     ```shell
     $ cd payload; make; cd ..
     ```
