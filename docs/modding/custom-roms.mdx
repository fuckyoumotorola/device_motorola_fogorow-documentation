## What is a Custom ROM?

A **Custom ROM** is a modified version of the Android operating system developed by third-party developers rather than the device manufacturer. Custom ROM projects are commonly based on **AOSP (Android Open Source Project)** and can include additional features, optimizations, customization options, security updates, and support for devices beyond their original software lifecycle.

Unlike a **GSI (Generic System Image)**, a Custom ROM is generally built and configured for a specific device or family of devices. Device-specific components such as the kernel, device configuration, hardware interfaces, vendor components, device tree, and partition layout may need to be integrated into the build.

Popular Custom ROM projects include **LineageOS, crDroid, Evolution X, PixelOS, ArrowOS**, and others. The exact features and supported devices depend on each project and maintainer.

| ✅ Advantages | ❌ Disadvantages |
|-|-|
|Access to newer Android versions after manufacter support ends|Potential bugs or incomplete hardware support|
|Additional customization and features|Installation is more device-specific than a GSI|
|Reduced manufacturer modifications and bloatware|Some features may require additional configuration or proprietary components|
|Community-developed updates and security patches|Incorrect flashing can cause bootloops or other software problems|
|Ability to use a different Android experience||
