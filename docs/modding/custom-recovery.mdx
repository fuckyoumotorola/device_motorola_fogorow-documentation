## TWRP

<img src={twrpImg} width="200" />

### Bugs
- Vibrator

### Install
1. Download [latest release](https://github.com/korzenroot/android_device_motorola_fogorow-twrp/releases/download/TeamWin/vendor_boot.img)
2. Reboot to [fastboot mode](../modes/fastboot)
3. Disable vbmeta (if partition not found - ignore)
    ```shell
    $ fastboot flash vbmeta vbmeta.img --disable-verity --disable-verification
    ```
4. Flash TWRP
    ```shell
    $ fastboot flash vendor_boot vendor_boot.img
    ```

## PBRP

<img src={pbrpImg} width="200" />

### Bugs
- Vibrator
- Flashlight

### Install

export const groupedPbrp = imagesPbrp.reduce((acc, item) => {
    if (!acc[item.android_version]) {
        acc[item.android_version] = [];
    }
    acc[item.android_version].push(item);
    return acc;
}, {});

{Object.keys(groupedPbrp).map(payload_version => (
    <details key={payload_version} className="custom-details">
        <summary>
            PBRP Android {payload_version}
        </summary>
        <ul>
            {groupedPbrp[payload_version].map(item => (
                <li key={item.android_version}>
                    <a href={item.url}>
                        {item.android_version}
                    </a>
                </li>
            ))}
        </ul>
    </details>
))}

<br />

1. Download release for your specific android version
2. Reboot to [fastboot mode](../modes/fastboot)
3. Disable vbmeta (if partition not found - ignore)
    ```shell
    $ fastboot flash vbmeta vbmeta.img --disable-verity --disable-verification
    ```
4. Flash PBRP
    ```shell
    $ fastboot flash vendor_boot vendor_boot.img
    ```
